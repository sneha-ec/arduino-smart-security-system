# Arduino-Based Smart Security System

## Overview
This project is an Arduino-based smart security system that uses an HC-SR04 ultrasonic sensor to detect nearby objects or intruders. When an object is detected within the specified distance, the Arduino activates a buzzer and an LED to provide an alert.

## Components Used
- Arduino Uno
- HC-SR04 Ultrasonic Sensor
- LED
- 220Ω Resistor
- Piezo Buzzer
- Breadboard
- Jumper Wires
- USB Cable

## Features
- Detects nearby objects using an ultrasonic sensor.
- Provides audio and visual alerts.
- Adjustable detection distance through code.
- Simple and low-cost security solution.

## Circuit
The circuit was designed and tested using Tinkercad before hardware implementation.

## Software
- Arduino IDE
- Tinkercad

## How to Run
1. Connect all components as per the circuit diagram.
2. Open the `.ino` file in Arduino IDE.
3. Select the correct board and COM port.
4. Upload the code to the Arduino Uno.
5. Test the system by placing an object in front of the sensor.

## Applications
- Home security
- Office security
- Restricted area monitoring
- Intrusion detection
